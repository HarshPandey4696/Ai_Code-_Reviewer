# AI Code Reviewer

> An intelligent, full-stack application that acts as your personal expert code reviewer. Powered by the **Google Gemini 2.0 Flash API**, it automatically analyzes your code for bugs, security vulnerabilities, performance bottlenecks, and best practice violations — in seconds.

![AI Code Review Tool Dashboard](client/src/assets/app.png)

---

## ✨ Features

### 🤖 AI-Powered Analysis
Submit any code snippet and receive a detailed, structured review generated by Google's Gemini 2.0 Flash model. The AI detects issues across four categories: bugs, security, performance, and best practices — and also highlights what you did well.

### 🖊️ Monaco Editor
The same editor that powers VS Code runs directly in the browser. Enjoy syntax highlighting, auto-indentation, and a familiar developer experience right inside the app.

### 📊 Scored Reviews
Every review comes with an **overall quality score (0–100)** so you can quickly gauge the health of your code at a glance.

### 📜 Review History
All reviews are automatically saved to MongoDB. Logged-in users see only their own reviews. Click any past review to instantly reload it.

### 🔐 JWT Authentication
Full register/login flow secured with **JSON Web Tokens** and **bcrypt** password hashing. Auth is optional — guests can still submit reviews, but won't get personalized history.

### ⚡ Redis Caching
Submitting the same code twice? The second result is returned **instantly** from Redis cache without calling the Gemini API again. Falls back gracefully if Redis is not installed.

### 🚦 Rate Limiting
Prevents API abuse with a limit of **10 reviews per IP per hour** using `express-rate-limit`.

### 📄 PDF Export
Download your complete code review as a formatted PDF using `jsPDF` and `html2canvas`.

### ⌨️ Keyboard Shortcut
Press `Ctrl + Enter` (or `Cmd + Enter` on Mac) to instantly submit code without reaching for the mouse.

### 🌙 Responsive Dark UI
A clean, responsive dark interface built with **Tailwind CSS v4**. Works on desktop and mobile.

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18 or higher
- **MongoDB Atlas** account — [free tier](https://www.mongodb.com/atlas) works fine
- **Google Gemini API key** — [get one free here](https://aistudio.google.com/app/apikey)
- **Redis** — optional, app works without it (caching is skipped gracefully)

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/yourusername/ai-code-reviewer.git
cd ai-code-reviewer
```

**2. Set up the server**
```bash
cd server
npm install
cp .env.example .env
# Open .env and fill in your values (see Environment Variables below)
node server.js
```

**3. Set up the client**
```bash
cd client
npm install
cp .env.example .env
# VITE_API_URL=http://localhost:5000
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🔐 Environment Variables

### Server (`server/.env`)

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | ✅ | Google Gemini API key from AI Studio |
| `MONGO_URI` | ✅ | MongoDB Atlas connection string |
| `JWT_SECRET` | ✅ | Random secret for signing JWTs (32+ chars) |
| `REDIS_URL` | ❌ | Redis connection URL (default: `redis://localhost:6379`) |
| `PORT` | ❌ | Server port (default: `5000`) |

Generate a secure JWT secret instantly:
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

### Client (`client/.env`)

| Variable | Required | Description |
|---|---|---|
| `VITE_API_URL` | ✅ | Backend base URL (e.g. `http://localhost:5000`) |

## 📡 API Reference

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `POST` | `/api/review` | Optional | Submit code for AI review |
| `GET` | `/api/history` | Optional | Fetch review history (filtered by user if logged in) |
| `GET` | `/api/review/:id` | None | Fetch a specific saved review by ID |
| `POST` | `/api/auth/register` | None | Register a new account |
| `POST` | `/api/auth/login` | None | Login and receive a JWT token |
| `GET` | `/api/auth/me` | Required | Get current authenticated user info |

## 🌐 Deployment

| Layer | Recommended Platform |
|---|---|
| Frontend | [Vercel](https://vercel.com) — auto-deploys on push |
| Backend | [Render](https://render.com) — free tier available |
| Database | [MongoDB Atlas](https://www.mongodb.com/atlas) — free 512MB cluster |
| Cache | [Redis Cloud](https://redis.io/cloud) — free 30MB instance |

**Deploying to Vercel (frontend):**
```bash
cd client
npm run build
# Then connect your GitHub repo to Vercel
# Set VITE_API_URL to your Render backend URL in Vercel env settings
```

**Deploying to Render (backend):**
- Set root directory to `server`
- Build command: `npm install`
- Start command: `node server.js`
- Add all env variables in the Render dashboard
